## Цель трека

В этом треке ты напишешь собственный интерпретатор Scheme на Scheme. Интерпретатор — программа, которая читает выражение и **вычисляет** его значение. К концу трека твой интерпретатор сможет вычислять числа, списки, условия, функции и рекурсию — настоящую программу на Scheme.

## Термы и атомы

Выражение для интерпретатора — обычные данные Scheme: числа, строки, символы и списки. Начнём с самого простого: **атомы**. Атом — это число, строка или булево значение. Такой атом «вычисляется сам»: его значение — он сам.

```scheme
42       ; значение — число 42
"привет" ; значение — строка "привет"
#t       ; значение — булево «истина»
```

Функция `interp` принимает два аргумента: выражение `expr` и окружение `env`. Окружение мы создадим в следующем уроке; пока передаём пустой список.

```scheme
(interp 42 '())        ; → 42
(interp "привет" '())  ; → "привет"
```

## Задание

Заполни ветки `cond`, чтобы `interp` возвращал атомы самими собой.

---starter
; Интерпретатор · Урок 1 — Атомы
;
; ЗАДАНИЕ: в каждой ветке cond верни само выражение expr,
; ведь число, строка и булево значение вычисляются сами.

(define (interp expr env)
  (cond
    ((number? expr) (error 'interp "ЗАДАНИЕ: число"))
    ((string? expr) (error 'interp "ЗАДАНИЕ: строка"))
    ((boolean? expr) (error 'interp "ЗАДАНИЕ: булево"))
    (else (error 'interp "непонятный атом" expr))))
---tests
(zchm-check-equal "число само себе" (interp 42 '()) 42)
(zchm-check-equal "снова число" (interp -7 '()) -7)
(zchm-check-equal "строка само себе" (interp "привет" '()) "привет")
(zchm-check-equal "булева истина" (interp #t '()) #t)
(zchm-check-equal "булева ложь" (interp #f '()) #f)
