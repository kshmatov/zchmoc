## Цель трека

Пока программа выполняет выражения строго по порядку, она использует только одно ядро и ждёт одну длинную операцию, даже когда свободны другие ресурсы. **Многозадачность** позволяет выполнять несколько независимых вычислений одновременно. В этом треке ты научишься запускать потоки, синхронизировать их, обмениваться данными и даже порождать отдельные процессы.

## Потоки

**Поток** — самостоятельная последовательность вычислений внутри одного процесса. Потоки выполняются параллельно (если ядер несколько) и разделяют одни и те же данные программы.

Запускает поток процедура `fork-thread`. Она принимает процедуру без аргументов и возвращает объект потока:

```scheme
(fork-thread (lambda () (display "я в потоке") (newline)))
```

Чтобы главная программа **дождалась** завершения потока, используется `thread-join`:

```scheme
(define t (fork-thread (lambda () (* 6 7))))
(thread-join t) ; ждём, пока поток t закончит работу
```

В R6RS потоков нет — это расширение Chez Scheme, и именно поэтому трек выполняется через системный sidecar: для настоящей параллельности нужен настоящий процесс, а не браузерная песочница.

## Параллельная работа

Классический приём — раздать независимые части работы по потокам. Например, заполнить вектор: каждый поток вычисляет свою ячейку независимо от остальных.

```scheme
(define (fill-squares v)
  (let ((n (vector-length v)))
    (let loop ((i 0) (threads '()))
      (if (= i n)
          (for-each thread-join threads) ; ждём все потоки
          (loop (+ i 1)
                (cons (fork-thread
                        (lambda () (vector-set! v i (* i i))))
                      threads))))))
```

## Задание

Реализуй `run-workers`: для каждого индекса `i` от `0` до `n-1` запусти отдельный поток, который выполнит `(work i)`, и дождись завершения всех потоков.

---starter
; Многозадачность · Урок 1 — Потоки
;
; ЗАДАНИЕ: дозаполни run-workers.
;   1) вместо (error …) при создании потока вызови fork-thread
;      с процедурой (lambda () (work i));
;   2) вместо (error …) в for-each дождись завершения потока t
;      через thread-join.

(define (run-workers n work)
  (let loop ((i 0) (threads '()))
    (if (= i n)
        (begin
          (for-each (lambda (t)
                      (error 'conc "ЗАДАНИЕ: дождись завершения потока"))
                    threads)
          'done)
        (loop (+ i 1)
              (cons (error 'conc "ЗАДАНИЕ: создай поток для (work i)")
                    threads)))))
---tests
(zchm-check "run-workers — процедура" (procedure? run-workers))

(let ((v (make-vector 5)))
  (run-workers 5 (lambda (i) (vector-set! v i (* i i))))
  (zchm-check-equal "каждая ячейка вычислена в своём потоке"
                    (vector->list v) '(0 1 4 9 16)))
