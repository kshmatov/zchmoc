## Процессы против потоков

Потоки живут внутри одного процесса и делят его память: быстро, но опасно для ошибок синхронизации. **Процесс** — полностью изолированная программа операционной системы: собственная память, собственное окружение. Процессы надёжнее, но обмениваются данными только через потоки ввода-вывода. Именно так устроены командная строка, шедулеры и серверы — запуск отдельной задачи отдельным процессом.

## Запуск процесса в Chez

Процедура `process` запускает внешнюю команду и возвращает список из трёх элементов: **порт чтения вывода** процесса, **порт записи в его ввод** и идентификатор процесса:

```scheme
(define p (process "cmd.exe /c echo hello"))
(car p)      ; порт чтения — читаем, что напечатал процесс
(cadr p)     ; порт записи — пишем процессу на вход
(caddr p)    ; pid — номер процесса
```

Читать вывод можно до конца потока — `get-char` вернёт `eof-object` (`eof-object?`), когда процесс закрыл свой вывод:

```scheme
(let loop ((acc '()))
  (let ((ch (get-char (car p))))
    (if (eof-object? ch)
        (list->string (reverse acc))
        (loop (cons ch acc)))))
```

Команда зависит от операционной системы: в примерах используется Windows (`cmd.exe /c …`), на Linux это были бы `sh -c` или `/bin/echo`.

## Задание

Реализуй `run-command`: запусти `cmd` через `process`, прочитай вывод процедурой `read-all` и закрой порты (порт вывода должен быть прочитан до `close-port`).

---starter
; Многозадачность · Урок 5 — Процессы
;
; ЗАДАНИЕ: в run-command запусти процесс командой cmd, из результата
; process возьми первый элемент — порт вывода, прочитай его через
; read-all и закрой оба порта.

(define (read-all p)
  (let loop ((acc '()))
    (let ((ch (get-char p)))
      (if (eof-object? ch)
          (list->string (reverse acc))
          (loop (cons ch acc))))))

(define (run-command cmd)
  (error 'conc "ЗАДАНИЕ: (process cmd), read-all по порту вывода, закрытие портов"))
---tests
(zchm-check "процесс запустился и вернул вывод"
            (zchm-contains? (run-command "cmd.exe /c echo привет-conc")
                            "привет-conc"))
