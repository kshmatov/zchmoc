Строки мы уже видели. Но в Scheme есть ещё один вид «имён» — **символы**.

## Символ — это не строка

Строка — последовательность символов-букв в кавычках. А **символ** — атомарное имя, которое обозначает себя самого как значение. Записывается с апострофом:

```scheme
'hello    ; символ hello
'привет   ; символ можно писать и по-русски
```

`'hello` — это сокращение от `(quote hello)`. Прочитай это так: «не вычисляй `hello`, а отдай его как есть». Проверка:

```scheme
(symbol? 'hello)   ; #t — символ
(symbol? "hello")  ; #f — это строка
(string? "hello")  ; #t
```

Символ и строка с одинаковым текстом — **разные** значения:

```scheme
(eq? 'hello "hello")  ; #f
```

## Зачем нужны символы

Символ — это значение, которое можно сравнивать и передавать. Имена — то, из чего строятся языки программирования: когда в треке «Интерпретатор» ты будешь разбирать код на части, именно символы будут обозначать имена переменных и вызовы процедур.

## Превращения туда и обратно

```scheme
(symbol->string 'hello)  ; "hello" — строка
(string->symbol "hello") ; 'hello — символ
```

(define (name-of sym)
  (error 'base "ЗАДАНИЕ: верни имя символа строкой"))

---tests
(define n1 (name-of 'hello))
(define n2 (name-of 'привет))
(define s1 (symbol-of "hello"))
(define s2 (symbol-of "привет"))

(zchm-check-equal "имя символа 'hello" n1 "hello")
(zchm-check-equal "имя символа 'привет" n2 "привет")
(zchm-check-equal "символ из строки \"hello\"" s1 'hello)
(zchm-check-equal "символ из строки \"привет\"" s2 'привет)
(zchm-check "name-of возвращает строку" (string? n1))
(zchm-check "symbol-of возвращает символ" (symbol? s2))
