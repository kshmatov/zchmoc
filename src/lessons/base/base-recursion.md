Циклов `for`/`while` в Scheme нет. Вместо них — **рекурсия**: процедура вызывает саму себя. Любая рекурсивная процедура строится из двух частей:

1. **базовый случай** — ответ, который вычисляется сразу (обычно это пустой список или нуль);
2. **рекурсивный шаг** — ответ сводится к тому же вопросу, но на меньших данных.

## Список по частям

У списка всегда есть «голова» — первый элемент — и «хвост» — остаток (список). Рекурсия по списку обычно смотрит на голову, а хвост передаёт дальше:

```scheme
(define (length-of lst)
  (if (null? lst)
      0                               ; базовый случай
      (+ 1 (length-of (cdr lst)))))   ; шаг: 1 + длина хвоста

(length-of '(a b c))   ; 3
```

## Считаем до нуля: хвостовая рекурсия

Когда рекурсивный вызов — **последняя** операция в процедуре (её результат сразу отдаётся наружу), это **хвостовой вызов**. Такая рекурсия не копит стек — Scheme выполняет её как обычный цикл.

Идиома «цикла» — именованный `let loop` с накопителем `acc` (accumulator). Элемент прикладывается к накопителю с **начала** списка, поэтому до нужного порядка его разворачивают:

```scheme
(define (make-range n)          ; список (1 2 ... n)
  (let loop ((i 1) (acc '()))
    (if (> i n)
        (reverse acc)           ; acc собрался как (n ... 1) — разворачиваем
        (loop (+ i 1) (cons i acc)))))

(make-range 5)   ; (1 2 3 4 5)
```
