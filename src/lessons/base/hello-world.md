Привет, Scheme!

Scheme — один из самых маленьких и стройных языков программирования. Программа на Scheme — последовательность **выражений**. Каждое выражение вычисляется и возвращает значение. Простейшие выражения — числа, строки и имена.

## Выражения

Введите в редакторе число — и нажмите «Запустить». Исполнитель вычислит выражение и покажет результат.

```scheme
42
```

## Вызов процедур

В Scheme почти всё — вызов процедуры. Вызов записывается в скобках: процедура идёт первой, аргументы — после неё.

```scheme
(+ 1 2 3)
```

`+` — процедура сложения; выражение выше возвращает `6`. Скобки можно вкладывать: значения внутренних выражений поступают в аргументы внешних.

```scheme
(* (+ 1 2) 4)
```

Считается сначала `(+ 1 2)` → `3`, затем `(* 3 4)` → `12`.

## Строки и вывод

Строка — последовательность символов в двойных кавычках. Процедура `display` выводит значение на экран — так мы увидим результат в панели вывода.

```scheme
(display "Привет, мир!")
```

`newline` — процедура без аргументов, печатает перевод строки.

```scheme
(display "первая строка")
(newline)
(display "вторая строка")
```

## Процедуры

Своя процедура определяется через `define` — имя, затем параметры в скобках, затем тело:

```scheme
(define (greet name)
  (display "Привет, ")
  (display name)
  (display "!")
  (newline))
```

Вызов процедуры с аргументом — как у `+`:

```scheme
(greet "Схемист")
```

## Задание

Определи процедуру `main`, которая выводит приветствие со словом «Привет». Дополни стартовый код (например, добавь к приветствию своё имя) и нажми «Проверить» — тесты проверят, что в выводе есть «Привет».

---starter
; Урок 1 · Hello, Scheme!
;
; Задание: определи процедуру main и выведи приветствие.
; Внутри main используй display и строку со словом «Привет».

(define (main)
  (display "Привет, Схемист!")
  (newline))
---tests
(zchm-check "main — процедура" (procedure? main))

(let ((s (zchm-capture-output main)))
  (zchm-check "вывод содержит «Привет»"
              (zchm-contains? s "Привет"))
  (zchm-check "вывод не пустой"
              (> (string-length s) 0)))
