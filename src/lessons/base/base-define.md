## Имена

`define` связывает имя со значением. Так создаются переменные и процедуры:

```scheme
(define pi 3.14)
(define (square n) (* n n))

(square pi)   ; 9.8596
```

Связанные имена видимы везде в программе ниже точки определения — это **глобальная видимость**. Значение имени берётся из окружающей области: процедура видит все имена, определённые снаружи.

## Локальные имена: let

Переменные можно заводить и локально, на время одного вычисления. Для этого служит `let` — он привязывает имена и вычисляет тело:

```scheme
(let ((dx (- x2 x1))
      (dy (- y2 y1)))
  (+ (* dx dx) (* dy dy)))
```

`let` вычисляет все значения сразу, поэтому связанные имена **не видят друг друга**:

```scheme
(let ((a 2)
      (b (* a 3)))   ; ошибка: a здесь ещё не связано!
  ...)
```

Если же хочется «шаг за шагом», когда следующее имя видит предыдущее, — используй `let*`:

```scheme
(let* ((a 2)
       (b (* a 3)))  ; теперь b = 6
  (+ a b))
```

## Процедуры внутри процедур

Внутри процедуры можно определять вспомогательные процедуры — они видят её параметры:

```scheme
(define (distance2 x1 y1 x2 y2)
  (define (square n) (* n n))
  (let* ((dx (- x2 x1))
         (dy (- y2 y1)))
    (+ (square dx) (square dy))))
```
