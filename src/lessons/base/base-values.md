Из первого урока запомнили: Scheme — про **выражения**. Каждое выражение вычисляется и даёт значение. Начнём с самых простых значений — тех, что не требуют вычисления вовсе.

## Само-вычисляемые значения

Числа, логические значения и строки набираются буквально и сразу становятся своим значением:

```scheme
42          ; число
3.14        ; число с дробной частью
#t          ; истина
#f          ; ложь
"текст"     ; строка
```

## Арифметика

Числа складывают, вычитают, умножают и делят. В Scheme почти всё — вызов процедуры, поэтому `+`, `-`, `*`, `/` пишутся в скобках:

```scheme
(+ 1 2 3)     ; 6
(- 10 4)      ; 6
(* 2 3 4)     ; 24
(/ 10 4)      ; 5/2 — точная дробь, а не 2.5!
```

`/` по умолчанию возвращает **точную рациональную дробь**. Это удобно: арифметика никогда не теряет точность.

Есть и целочисленное деление:

```scheme
(quotient 7 3)  ; 2 — целая часть
(remainder 7 3) ; 1 — остаток
```

## Сравнения

Сравнения возвращают `#t` или `#f`:

```scheme
(< 2 5)       ; #t
(> 2 5)       ; #f
(= 4 4)       ; #t
(<= 3 3)      ; #t
```

`=` сравнивает числа (и дроби: `(= 5/2 2.5)` — `#t`; осторожно, десятичные дроби в Scheme — точность как у плавающей точки, про это позже).
