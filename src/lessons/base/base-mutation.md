До сих пор имена были неизменяемыми константами. Но иногда состояние должно **меняться**. Для этого существуют две вещи: `set!` и ячейки (boxes).

## set!

`set!` перезаписывает связанную переменную:

```scheme
(define x 1)
(set! x (+ x 1))
x   ; 2
```

Менять имена стоит в исключительных случаях — но именно на этом построен настоящий изменяемый мир (а заодно и трек «Многозадачность»).

## Проблема: значения не изменяются «изнутри»

Процедура получает копию значения и не может повлиять на внешнее имя:

```scheme
(define (bump n) (set! n (+ n 1)) n)   ; меняет свою копию
(define v 10)
(bump v)   ; 11 — временно
v          ; 10 — снаружи пусто
```

Чтобы общий объект действительно изменялся, нужна **ячейка** (box):

```scheme
(define b (box 10))          ; ячейка со значением 10

(unbox b)                    ; 10 — достать значение
(set-box! b (+ (unbox b) 1)) ; положить новое значение внутрь той же ячейки
(unbox b)                    ; 11
```

Ячейка — это объект, который можно передавать куда угодно; `set-box!` меняет его **содержимое**, поэтому все, у кого есть ссылка на ячейку, увидят новое значение.

## Счётчик на замыканиях и ячейке

Сочетая замыкания (урок 8) и ячейки, получаем настоящий счётчик:

```scheme
(define (make-counter)
  (let ((n (box 0)))
    (lambda ()            ; у всех, кто получил эту процедуру,
      (set-box! n (+ (unbox n) 1))   ; — одна и та же ячейка
      (unbox n))))
```

`make-counter` всегда возвращает **новую** независимую ячейку.
