Scheme всё время задаёт вопросы значениям: «это число?», «это список?», «они равны?». Процедуры, отвечающие `#t` или `#f`, называются **предикатами**.

## Проверка типов

```scheme
(number? 42)     ; #t
(string? "hi")   ; #t
(symbol? 'hi)    ; #t
(pair? '(1 2))   ; #t
(null? '())      ; #t
(boolean? #t)    ; #t
```

Предикат-вопрос полезен, когда к значению нужно применить подходящую операцию:

```scheme
(if (pair? xs) (car xs) 'none)
```

## Равенство: три уровня

Равенство в Scheme — три отдельные процедуры:

| Процедура | Сравнивает | Пример |
|-----------|-----------|--------|
| `eq?` | идентичность объекта (для символов — всегда надёжно) | `(eq? 'a 'a)` → `#t` |
| `eqv?` | то же + числа | `(eqv? 42 42)` → `#t` |
| `equal?` | структурное равенство любых значений | `(equal? '(1 2) (list 1 2))` → `#t` |

`equal?` — самый «прощающий»: сравнивает содержимое списков, строк, всё содержимое целиком. `eq?` — самый строгий: два разных списка с одинаковыми элементами для него — разные объекты:

```scheme
(equal? '(1 2) '(1 2))  ; #t — содержимое одинаковое
(eqv? '(1 2) '(1 2))    ; #f — это разные пары (в Chez)
(eq? 'x 'x)             ; #t — символы равны всегда
```

Правило выбора: для символов — `eq?`, для чисел — `eqv?`, для всего остального и в сомнениях — `equal?`.

; его первый элемент; для пустого списка и любых других значений
; вернуть символ 'none. Используй pair? и if.

(define (first-or-none lst)
  (error 'base "ЗАДАНИЕ: верни первый элемент или 'none"))
---tests
(define f1 (first-or-none '(яблоко груша)))
(define f2 (first-or-none '()))
(define f3 (first-or-none 42))

(zchm-check-equal "первый элемент списка" f1 'яблоко)
(zchm-check-equal "пустой список → none" f2 'none)
(zchm-check-equal "не список → none" f3 'none)
(zchm-check "pair? распознаёт список" (pair? '(1 2 3)))
(zchm-check "eq? сравнивает символы" (eq? 'x 'x))
(zchm-check "eqv? сравнивает числа" (eqv? 2 (+ 1 1)))
(zchm-check "equal? сравнивает содержимое" (equal? '(1 2) (list 1 2)))
