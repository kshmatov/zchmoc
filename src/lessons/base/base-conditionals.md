Программа, которая делает одно и то же всегда, — скучна. Ветвления позволяют выбирать путь вычисления.

## if

`if` — базовое ветвление, выбирает одно из двух выражений в зависимости от условия:

```scheme
(if (> x 0)
    "положительное"
    "не положительное")
```

Условием считается всё, кроме `#f` — даже `0`, `'()` и пустая строка считаются истиной:

```scheme
(if '() "истина" "ложь")   ; "истина" — только #f ложно!
```

## cond

Когда вариантов больше двух, на помощь приходит `cond` — лесенка из проверок сверху вниз; срабатывает первая истинная:

```scheme
(define (describe n)
  (cond
    ((< n 0) "отрицательное")
    ((= n 0) "ноль")
    (else "положительное")))
```

Ключ `else` ловит всё, что не подошло.

## and, or

`and` проверяет все аргументы по порядку: вернёт `#f` или значение последнего проверенного; `or` — первое истинное или `#f`:

```scheme
(and (< 1 2) (< 2 3))  ; #t
(and #t 'yes)          ; yes — последнее значение
(or #f 'fallback)      ; fallback — первое истинное
```

## when, unless

Когда к ветви ничего не приделать, `when` и `unless` делают одну ветку проще:

```scheme
(when (> score 90) (display "отлично"))
(unless (list? xs) (display "не список"))
```
