Процедуры, которые принимают другие процедуры как аргументы (или возвращают их), называются **процедурами высшего порядка**. Ты уже видел одну — `compose`. Вот самая полезная троица для работы со списками.

## map — применить ко всем

`map` строит новый список, применяя процедуру к каждому элементу:

```scheme
(map (lambda (x) (* x x)) '(1 2 3 4))   ; (1 4 9 16)
```

## filter — оставить подходящих

`filter` оставляет только те элементы, для которых предикат вернул истину:

```scheme
(filter (lambda (x) (> x 0)) '(3 -1 0 5))   ; (3 5)
```

## fold-left — свернуть в одно

`fold-left` проходит список слева направо, накапливая результат:

```scheme
(fold-left + 0 '(1 2 3 4))   ; 10 — (((0+1)+2)+3)+4

;; то же самое, но с явным аккумулятором:
(fold-left (lambda (acc x) (+ acc x)) 0 '(1 2 3 4))
```

`+` — это просто процедура двух аргументов, и `fold-left` передаёт ей накопленное значение и очередной элемент.

Напиши две процедуры над списками.

---starter
; Урок 10 · Процедуры высшего порядка
;
; ЗАДАНИЕ 1: (sum-squares lst) — сумма квадратов элементов списка.
; Сначала map: возведи каждый элемент в квадрат, затем fold-left: сложи.
; Для пустого списка — 0.
;
; ЗАДАНИЕ 2: (positive-only lst) — список из положительных элементов.

(define (sum-squares lst)
  (error 'base "ЗАДАНИЕ: сложи квадраты элементов через map и fold-left"))

(define (positive-only lst)
  (error 'base "ЗАДАНИЕ: оставь только положительные через filter"))
---tests
(define ss1 (sum-squares '()))
(define ss2 (sum-squares '(1 2 3)))
(define p1 (positive-only '(3 -1 0 5)))
(define p2 (positive-only '(-1 -2)))

(zchm-check-equal "сумма квадратов пустого" ss1 0)
(zchm-check-equal "1² + 2² + 3²" ss2 14)
(zchm-check-equal "только положительные" p1 '(3 5))
(zchm-check-equal "все отрицательные → пусто" p2 '())
