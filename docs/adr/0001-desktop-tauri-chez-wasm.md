# Десктоп-приложение на Tauri с исполнителем кода на Chez Scheme (WASM)

zchemer — десктоп-приложение в корпусе Tauri с веб-интерфейсом; исполнитель кода — R6RS-интерпретатор Chez Scheme, компилируемый в WASM. Продвинутые треки (сырые TCP/UDP, базы данных, HTTP-серверы) требуют реальных процессов, сокетов и файловой системы, чего не даёт браузерная песочница. Tauri выбран как более лёгкий и нативный, чем Electron, при тех же возможностях встраивания веб-интерфейса. Chez Scheme — единственный зрелый интерпретатор с полным R6RS, пригодный для компиляции в WASM, поэтому он и есть исполнитель кода, а не собственный интерпретатор.

## Considered Options

- **Чистое веб-приложение**: отклонено — браузер не даёт настоящих сокетов, процессов и файловой системы для треков сети, БД и многозадачности.
- **Electron**: отклонено — те же возможности, что у Tauri, но тяжелее и менее нативен.
- **Собственный интерпретатор как исполнитель кода**: отклонено — огромный объём, дублирующий зрелую R6RS-реализацию; собственный интерпретатор остаётся прерогативой одноимённого трека.

## Consequences

Путь сборки подтверждён: официальный флаг `--emscripten` в BUILDING Chez собирает рантайм через Emscripten, есть готовые npm-пакеты (`chez-scheme-js`, `@odradekk/vera-scheme-sandbox`). Запасные варианты (BiwaScheme, LIPS) покрывают R5RS/R7RS, но не R6RS — для точности к стандарту они не подходят.
