# План базового трека (base)

**Цель**: довести новичка с нуля до уверенного владения ядром Scheme — настолько, чтобы любой из трёх треков-проектов (интерпретатор, сеть, многозадачность) был комфортен.

**Ограничения исполнителя**: трек `base` (и `interpreter`) выполняется в WASM-Chez (браузерная песочница), поэтому уроки используют только чистые возможности языка: выражения, процедуры, списки, рекурсию. Никакого системного доступа (`load-shared-object`, потоки, процессы, сеть). Тесты — тот же формат, что и в sidecar-треках: секция `---starter` + `---tests`, харнесс `zchm-check`/`zchm-check-equal`/`zchm-capture-output`/`zchm-contains?`.

**Стартовое состояние**: в треке есть один урок — `hello-world` (order 1). План ниже описывает, что добавить.

## Как устроен трек

- Формат урока — один файл `src/lessons/base/<id>.md`, как у существующих треков (frontmatter с `skills`, theory, `---starter`, `---tests`).
- Порядок строго последовательный: каждый урок опирается только на навыки предыдущих.
- Названия навыков — новые строковые идентификаторы (см. `skills` ниже); в будущем треки-проекты смогут указывать их как требования-пререквизиты.
- Каждый новый урок проверяется прогоном его тестов в WASM-исполнителе (тот же `buildTestProgram` из `src/lib/test-harness.ts`).

## Связь с треками-проектами

Каждый трек-проект опирается на конкретные навыки базового трека:

- **Интерпретатор** — самое требовательное ядро: темы 3–9 целиком (символы, пары/списки, `quote`, `if`, `lambda`/замыкания, `define`/рекурсия, окружения). Уроки-проекта уже существуют и предполагают именно этот уровень.
- **Сеть** — темы 1–2, 6, 7, 9, 11 (арифметика, строки/байты, рекурсия-циклы, написание процедур). Дополнительно читаются уроками сети.
- **Многозадачность** — темы 1–2, 6, 7, 9, 12 (состояние, циклы, замыкания для общих ячеек). Дополнительно — уроками многозадачности.
